# План покатушок: діагностика витрати газу (Corolla E150 1.6 + Stag BASIC)

Мета: одна поїздка на 50–70 хв, з якої видно:
1. чи переливає/недоливає Stag відносно бензину, і **в яких зонах** обертів/навантаження;
2. чи прогрівається мотор до 85–95 °C і тримає температуру на трасі (термостат);
3. як працює лямбда;
4. скільки додає кондиціонер;
5. скільки палива двигуну **реально треба** (оцінка з MAF) порівняно з фактичними 14 л/100 км.

---

## Напередодні / зранку перед поїздкою

- [ ] Двигун **холодний** (стояв ніч) — потрібен холодний старт.
- [ ] Газу ≥ 1/2 бака, бензину ≥ 1/4 (буде 15–20 хв на бензині).
- [ ] Бажано: **заправити газ «під відсічку»** і записати пробіг — наступна заправка дасть
      реальну витрату для порівняння з оцінкою з MAF.
- [ ] Тиск у шинах — за табличкою на стійці.
- [ ] Ноутбук: живлення від прикурювача, сон вимкнено, закриття кришки = «нічого не робити».
- [ ] Маршрут: місто → ділянка траси, де можна їхати **5+ хв рівно 70 і 90 км/год**, двічі
      (на газу й на бензині — **та сама ділянка**).
- [ ] Бажано другу людину: водій їде, штурман тисне клавіші.

## Спарювання ELM327 (один раз, у машині)

1. Вставити ELM в OBD-роз'єм (під кермом ліворуч), **запалювання ON**.
2. Windows: `Параметры → Устройства → Bluetooth и другие устройства → Добавление Bluetooth`
   → `Bluetooth` → пристрій `OBDII` / `OBD2` / `V-LINK` → PIN **1234** (або 0000 / 6789).
3. `Другие параметры Bluetooth → вкладка COM-порты` — має бути **Исходящий COMx** для OBDII.
4. Перевірка: подвійний клік `logger\probe.bat` — має показати версію ELM, протокол
   `ISO 15765-4 (CAN 11/500)` і список PID. **Скинути мені цей вивід** — підтвердимо PID-и
   (MAF є? лямбда B1S1 вузькосмугова чи A/F-датчик?).

## Порядок запуску (кожна поїздка)

1. Запалювання **ON, мотор не заводити.**
2. AC STAG → підключиться сам (Порт → Автопоиск; інакше Порт → Соединить); записати стан ISA-3
   (Параметры → Расширенные настройки → Автоадаптация → Конфиг.); осцилограф **Старт диаграммы**.
3. `logger\run_logger.bat` → дочекатись рядка зі статусом (Hz, STFT, LTFT, ECT).
4. **Позначки — клавішами у вікні логера** (працює і в укр. розкладці):

| клавіша | значення |
|---|---|
| `g` | перейшов на **газ** (Stag перемкнувся / зелений світлодіод) |
| `b` | перейшов на **бензин** (кнопка на перемикачі) |
| `a` / `s` | кондиціонер **увімк.** / **вимк.** |
| `h` / `c` / `i` | **траса** / **місто** / **холості** |
| `m` | довільна позначка (нумерується m1, m2…) — перегазовки, «щось дивне» |
| `q` | завершити запис |

   **На старті одразу натиснути `b`** (холодний мотор іде на бензині) і `s` або `a` за станом A/C.
   Вікно логера має бути активним (у фокусі), коли тиснете клавішу! Якщо переключились в AC STAG —
   клікніть назад у вікно логера.

**Ручний тест калібровки (бонус, на кроках 4–5 і 7):** на рівній швидкості запам'ятати Б1
(час впорску бензину) у Мониторі → перемкнути паливо → через 30 с порівняти Б1. Записати
пари «швидкість / Б1 на бензині / Б1 на газу» у блокнот (або голосовою нотаткою) — це найпряміший
показник, у якій точці множник завеликий/замалий.

## Якщо щось пішло не так

- **Логер пише «connect failed / no data»** — перевірити запалювання; ELM «заснув» → вийняти/вставити.
  Логер сам перепідключається, файл той самий, нічого не втрачається.
- **Hz < 1.5** — BT-клон повільний; нічого страшного, але можна перезапустити з `--single`,
  якщо в лозі є «multi-PID … falling back».
- **Stag не переходить на газ** — дивитись температуру редуктора («Ред.») у Мониторі.
- Ноут/програма зависли — дані до цього моменту вже на диску (запис щорядково).

## Після поїздки

1. Файли осцилографа Stag — у `stag\osc\` (краще одразу зберігати туди через «Запись диаграммы»),
   скріншоти — у `stag\screens\`. Годинник ноутбука не чіпати: за ним зводяться ELM і Stag.
2. `logger\analyze.bat` → звіт `analysis/<лог>/report.md` + PNG.
3. Разом розбираємо: звіт ELM + карти B/G/D + осцилограми → план корекції множника.

## Що шукаємо (критерії)

| Гіпотеза | Підтверджується, якщо |
|---|---|
| Калібровка Stag | STFT+LTFT на газу нижче бензинових на > 3 п.п. в тих самих клітинках; D Б-1 у Stag додатне; Б1 коротшає після перемикання на газ |
| Термостат | ECT < 80 °C після 10+ хв руху або падає на трасі нижче 80–82 °C |
| Лямбда | повільні / рідкі перемикання, розмах < 0.1–0.8 В, «лінивий» відгук на перегазовку |
| Кондиціонер | MAF/навантаження з A/C на > 10–20 % вище на тих самих швидкостях |
| Мотор (не Stag) | трими великі (> ±8 %) **і на бензині** |
| Витрата «в open loop» | оцінка з MAF ≈ 11–12 л/100 км, а по заправках 14 → надлишок у розгонах/прогріві |
