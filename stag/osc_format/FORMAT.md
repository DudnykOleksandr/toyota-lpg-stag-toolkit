# Формат файлів осцилографа AC STAG (`*.osc`)

Розібрано 2026-09-25 за демо-файлами з `AC STAG 0.64.4\Demo\` і перевірено по значеннях,
які сама програма показує в демо-режимі (монітор + «Информация о файле»). Парсер:
[`logger/stag_osc.py`](../../logger/stag_osc.py).

Усі цілі числа **big-endian**, без стиснення й шифрування.

| Що | Формат | Приклад (QBOX Basic) |
|---|---|---|
| сигнатура | `"Ugic_Osc"` | 0x0000 |
| налаштування відображення | записи по 18 байтів (лінії осцилографа / кольори), не розібрано | 0x0016… |
| довжина таблиці каналів | `u16` (кратна 10) | 0x0B9C: `0x017C` = 380 |
| таблиця каналів | N × `{u8 id; f64 scale; u8 size}`, **перший запис — нулі**; `scale = 0` — бінарний блок довільного розміру | 38 записів (демо), 40 (авто) |
| довжина даних | `u32` | 0x0D1A: `0x9720` = 38688 |
| дані | записи = канали в порядку таблиці, `size` 1/2/4 байти, беззнакові | 403 × 96 байтів |
| трейлер | `… u32 start_unix, u32 end_unix (UTC), u32 n_samples …`, далі дата прошивки (`1c 05 07e2 0c 05 1b` = 28.05.2018 12:05:27) і серійний номер | 0xA445 |

**Значення = raw × scale.** Мітки часу окремих вибірок не зберігаються: вибірки рівномірно
розподілені між `start` і `end` (у демо ≈ 9 Гц). Час береться з годинника ПК, на якому писали, —
той самий ноутбук, що й ELM-логер, тому записи зводяться за часом напряму.
