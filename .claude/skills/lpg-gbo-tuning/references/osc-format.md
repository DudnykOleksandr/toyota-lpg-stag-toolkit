# Формат `.osc` (осцилограф AC STAG) — коротко

Розібрано за демо-файлами AC STAG 0.64.4. Парсер: `logger/stag_osc.py` у проєкті (якщо його немає — формат нижче достатній, щоб написати заново за 50 рядків).

- Сигнатура `"Ugic_Osc"`. Усі цілі — **big-endian**, без стиснення.
- `u16 table_len` (кратне 10) → таблиця каналів `table_len/10 × {u8 id; f64 scale; u8 size}`, **перший запис — нулі**.
- `u32 data_len` → записи; довжина запису = сума `size` каналів; поля в порядку таблиці, беззнакові. **value = raw × scale**.
- Трейлер одразу після даних: `… u32 start_unix, u32 end_unix (UTC), u32 n_samples …`, потім дата прошивки й серійний номер.
- Мітки часу окремих вибірок не зберігаються → рівномірно між start і end (демо: ≈9 Гц). Час — годинник ПК, на якому писали.
- Пошук таблиці: сканувати файл на `u16 L` з L%10==0, 10 нульових байтів після, валідні записи (size ∈ {1,2,4}, 0<scale<1e6), і `u32 data_len`, кратний сумі size.
