## 2. Вкладка «Параметры»

Підвкладки: **Параметры автомобиля** · **Настройки блока управления газа** · **Расширенные настройки** · **Информация об автомобиле**.

- *Параметры автомобиля*: кількість циліндрів, тип двигуна/впорску, джерело сигналу обертів, «Сигнал оборотов» (поріг, В), Лямбда-зонд 1/2 (По напряжению / UEGO / Не подключен).
- *Настройки блока управления газа*: «Переключение на газ» (Порог переключения rpm, Время, Задержка наполнения, **Темп переключения** °C, Перекл. цилиндра мс, Теплый старт…), «Переключение на бензин» (Мин./Макс. обороты на газе, Время ошибки давления, Мин. темп. газа, **Макс. нагрузка на газе**), «Параметры калибровки» (**Рабочее давление**, Минимальное давление, Темп. газа калібровки — лише читання), «Датчики и исполнительные элементы» (**Тип газ. форсунки** + кнопка «…» = налаштування форсунок: корекції по циліндрах, послідовність, тест потоку).
- *Расширенные настройки*: Аварийные запуски, Сброс давления, **Доля бензина** (дотриск бензину), Подогрев форсунок, **Обеднение на холодном двигателе**, Холодный VAG, **Прочее → Автоадаптация (активная) + «Конфиг.»**, Предв. запол. системы, звукові сигнали.

## 3. Вікно «Автоадаптация» (ISA-3)

У BASIC з новою прошивкою **ISA-3 є** (мануал 2022 пише «лише PLUS» — застаріло). Вікно може вискочити саме при підключенні.
Поля: Включено ☐ · режим OBD (у BASIC неактивний) / **ИСА-3** · Параметры: **STFT банк1** (поточна корекція ISA-3, %), **Мгнов. отклонение банк1**, Режим ISA3 OL · Конфигурация: **Порог включения адаптации** (4 %), **LTFT макс.** (25 %), Адаптация в OL, Автодополнение карты, Авто стоп.

⚠ **Знак «Мгнов. отклонение банк1» протилежний карті D:** тут + = Б на газу довший = **бідно** (у D + = багато).
На BASIC ISA-3 працює лише з підключеним проводом лямбди (фіолетовий, паралельно верхній лямбді) і ввімкненою лямбдою в «Параметры автомобиля»; з'явилась у прошивці 2.10.2 (2018).

ISA-3 підганяє дозу газу так, щоб час впорску бензину на газу збігся з **картою Б** (еталон, зібраний на бензині). Наслідки:
- видалення карти Б знищує еталон автоадаптації;
- при ввімкненій ISA-3 «Подбор множника» заблокований (підказка «ИСА-3 включена — соответствия неактивны»);
- якщо ISA-3 активна і працює, трими газ/бензин будуть близькі, а помилка калібровки ховається в корекції ISA-3 — дивитись «STFT банк1» і MAP-корекцію.

## 4. Вкладка «Карты»

Підвкладки: **Множитель (Б-1)** · **Кор. оборотов** · Доля бензина · Кор. темп. газа · Кор. темп. ред. · Кор. давл. газа · **Б Б-1** · **Г Б-1** · **D Б-1** · **MAP корр. Б-1** · Доля бензина (от Давл.ГАЗа).

Іконки ліворуч від «Множитель» (підписи зі спливних підказок):

| Іконка | Підказка | Безпека |
|---|---|---|
| синій хрест | **Удалить B** | ⛔ стирає бензинову карту (еталон ISA-3) |
| зелений хрест | **Удалить G** | ⛔ стирає газову карту |
| Б-2 | Переключить банк 1 / банк 2 | лише V-двигуни |
| стрілки по колу | Подбор множителя (при ISA-3 заблоковано) | ⚠ змінює множник |
| квадрат | Автоматический выбор | безпечно |
| червоно-синій графік | **Отклонение** | безпечно, показує лінію D |
| «Акс.» | Выбор единицы измерения | безпечно |

На «Кор. оборотов»: Удалить (⛔), Автоматический выбор, **Конфигурация карты** (лише межі осей: макс. час впорску, кількість стовпців), Map active/inactive.

Редагування множника (з мануалу): клік по жовтій точці → значення в правому нижньому куті; ↑/↓ — множник, ←/→ — положення по часу впорску, Shift = ×10, Insert — додати точку, Delete — видалити точку, PgUp/PgDn — ±10 (усю карту, якщо точка не вибрана), Ctrl+←/→ — наступна точка, **Space під час їзди — вибрати точку біля курсора**. Зміни діють одразу (окремої кнопки «записати» немає).
«Кор. оборотов»/«MAP корр.»: виділити область мишею (або Shift+стрілки) → Ctrl+↑/↓ збагатити/збіднити (Shift ×10).

**Окремої кнопки «зберегти карту в файл» у BASIC немає** — єдина цифрова копія = «Инструменты → Сохранить настройки».

Карта D: **додатне = на газу багато** (час впорску бензину на газу коротший за еталонний). Мануал: норма ±10 %; на малих навантаженнях природний розкид більший — не гнатися за нулем.

## 5. Монітор (права панель)

Давление: **Газ**, **MAP** [бар] · Время впрыска/доза [мс]: **Б1–Б4** (бензин), **Г1–Г4** (газ) · Температура: Газ, **Ред.**, Внутренняя, Эмул. двиг-ля · Другие: **Лямбда 1**, Питание · Обороты · Нагрузка двигателя %. Клік по сигналу вмикає/вимикає його в осцилографі. Іконки форсунок — тимчасово вимкнути циліндр на газ (діагностика).

## 6. Осцилограф

Кнопки внизу: **Старт диаграммы** · **Стоп диаграммы** · **Запись диаграммы** (зберегти `.osc`) · **Считывание диаграммы** (відкрити) · масштаб − / + · **Информация о файле** (початок/кінець, кількість вибірок, версія, серійник) · Поиск / пред. / след. · Отобразить/скрыть все параметры. Зелена лінія зверху = робота на газу. Зберігати запис кожні 15–20 хв. Формат файлу — `osc-format.md`.

## 8. Розбіжності мануалу 2022 і програми 0.64.4

- Порт вибирається автоматично («Автопоиск»), а не зі списку COM.
- ISA-3 доступна в BASIC.
- Вкладки «Ошибки» в демо BASIC немає (можливо, з'являється при підключенні).
- Назви бензинових/газових форсунок у моніторі: Б/Г (у мануалі P/G).
