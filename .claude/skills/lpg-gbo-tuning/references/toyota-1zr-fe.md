# Toyota Corolla E150 / Auris 1.6 1ZR-FE на ГБО

Джерело: `research/lpg/03_corolla_1zr_fe.md` (повні посилання там). Позначки: [M] кілька джерел, [S] одне джерело, [F] форум, [D] розрахунок/висновок.

## Двигун
- 1598 см³ (≈400 см³/цил.), ε 10,2, 91 кВт / 122–124 к.с. @ 6400, ланцюг, Dual VVT-i, без EGR, порядок роботи 1-3-4-2, холості ≈700 об/хв, бензин 95 RON, тиск бензину ≈300 кПа (безповоротна система). [M]
- **Витратомір MAF (гарячий дріт) з вбудованим IAT, датчика MAP немає.** По OBD: PID 0x10 є, 0x0B — найімовірніше ні. Stag бере розрідження зі свого датчика MAP. [M]
- **Верхня лямбда (EU/RU): вузькосмугова 4-провідна** 89465-12880 / 89465-02310 (Denso DOX-0542). toyota-club.net пише про A/F-датчик 89467 — ймовірно, інші ринки. Перевірка: PID 0x14 перемикається 0,1↔0,8 В → вузькосмугова; якщо ECU дає 0x24/0x34 — A/F. Нижня — звичайна вузькосмугова (89465-02280). [M з розбіжністю]
- Бензинові форсунки з подовженим носиком (Denso EV14, 12 отворів). **Час впорску бензину на прогрітих холостих ≈1,9–2,25 мс** [F] → потрібні **швидкі** газові форсунки (напр. ALEX Barracuda мін. 2,0 мс, Super B мін. 1,6 мс; повільні рейки на кшталт RAIL-001 хочуть ≥3 мс).
- **Клапани: роликові коромисла на гідрокомпенсаторах — зазорів немає, регулювати нічого.** Цифри 0,15–0,25 / 0,25–0,35 мм — це 1ZZ-FE. [M]
  Наслідок для газу: просідання сідел гідрокомпенсатор ховає, доки не вичерпає хід → потім клапан не закривається (компресія ↓, пропуски, прогар, витрата ↑). **Єдина практична перевірка — компресія / пневмотест**, орієнтовно кожні 30–40 тис. км на газу і щоразу, коли зросла витрата чи «трясе» на холостих. [D]
- Перевірка гідрокомпенсатора: поршень 1 у ВМТ, натиснути на коромисло — якщо йде майже без зусилля, компенсатор несправний; стукіт після холодного пуску. [S]

## Репутація на газу
- Загалом добре переносить ГБО: AutoCentrum 4,6/5 (STAG 300 Premium, BRC Sequent), звіт 110 тис. км на газу без проблем з мотором (лише 2 котушки). [F, агреговано]
- Є скарги на «м'які» сідла й поодинокі прогари/пробої прокладки (зв'язок з газом не завжди доведений). [F]
- Flashlube / Valve Saver: польські бази — не потрібно (гідрокомпенсатори); англомовна стаття — потрібно (на хибній передумові). Позиція: необов'язкова дешева страховка при великих пробігах; важливіше не допускати бідної суміші на газу під навантаженням і стежити за компресією. [F/D]
- Редуктори, що зустрічаються: Tomasetto AT09 / Nordic, KME Silver, STAG R02 — будь-який на ~120–170 к.с. Польський форум радить уникати редукторів AC (нестабільний тиск). [F]
- Сопла (таблиця ALEX): 31 к.с./цил. → **≈2,2–2,5 мм при 1,0–1,3 бар**; за об'ємом 1ZR на межі 2,5/2,8 мм. Час газу на холостих — трохи вище стабільного мінімуму рейки (у прикладі з drive2 цільові 3,4–3,5 мс для Barracuda). [S/F]
- Робочий тиск зазвичай **1,0–1,2 бар**; вищий — коротше життя форсунок. [F/M]

## Охолодження / термостат
- **Термостат відкривається при 82 °C** (повністю ≈95 °C). **Норма по OBD (PID 0x05): 86–94 °C.** [M]
- **Стрілка приладки показує «норму» вже з ≈78 °C** (середина шкали ≈53 °C) → термостат, що застряг відкритим (68–75 °C), видно лише по OBD. [S]
- Взимку на максимальній пічці рідина може падати < 70 °C і термостат «клацає» — не плутати з несправністю. [S]
- P0128 у таблиці DTC 1ZR-FE не знайдено → несправний термостат може **не запалювати check**. [S]
- На газу холодний мотор = довший Б (прогрівне збагачення) → Stag пропорційно довший Г; плюс холодніший редуктор/газ і пізніше перемикання. +5–15 % взимку правдоподібно. [D]
- Буває, що редуктор врізаний у контур підігріву дросельної заслінки — тоді проблеми з потоком у цьому контурі вдаряють і по редуктору. [F]

## OBD
- Пізніші машини: **ISO 15765-4 CAN 11 біт 500 кбіт/с**, ECM 7E0/7E8. Ранні (2007–2008) можуть бути на K-line (ISO 9141-2) — лише автовизначення протоколу. АКПП керує той самий ECM. [S/D]
- Очікувані PID: 04, 05, 06/07, 0C/0D, 0E, 0F, **10 (MAF)**, 11, 13, **14/15 (якщо вузькосмугова)**; 0B — навряд.
- Час впорску в мс, «AF lambda», значення навчання — лише в Toyota enhanced data (Techstream), не в стандартному OBD. Витрату оцінюємо з MAF. [D]
- **Трими:** норма сумарно ≈±10 %; **P0171/P0172 при STFT+LTFT ≈ ≥+35 / ≤−35 %** (ECT > 75 °C; інші моделі Toyota +33/−30 або ±38). На польських форумах про «бідні» коди з LTFT ≈ +24 % на газу. [S/F]
- **Трими спільні для обох палив.** **Скидання помилок звичайним сканером (mode 04) НЕ скидає LTFT** у Toyota → EFI-запобіжник ≥1 хв, або клема акумулятора ≥15 хв, або Techstream «Learning Value Reset». Після скидання — кілька циклів переучування. [M]
- Орієнтири: MAF на прогрітих холостих ≈1,5–2,5 г/с, LOAD ≈15–25 % [S/F]; 90 км/год ≈15–16 г/с, LOAD 30–40 % [D, без джерела].

## Витрата — що вважати нормою
- Бензин 1,6 АКПП: паспорт 9,3 місто / 6,0 траса / 6,9–7,2 змішаний; власники 9,1–9,5 змішаний, 12–13,5 зимове місто з короткими поїздками. [M/F]
- Газ ≈ **1,15–1,25 × бензин** за об'ємом: власники 9,0–10,7 л/100 км. [F/S]
- **12 л газу — правдоподібно для міста з АКПП; +17 % (12→14) на тому ж маршруті й сезоні — ненормально.** Порядок перевірки: ECT по OBD → трими газ/бензин по клітинках → стабільність тиску редуктора і температура газу, фільтри → пропуски (котушки 1ZR виходять з ладу **без DTC**; свічки, зазор 1,1 мм, на газу трохи менший) → компресія → MAF → повільна верхня лямбда. [D]
- Якщо зростання лише взимку і збігається з нижчою ECT — спершу термостат/пічка.
